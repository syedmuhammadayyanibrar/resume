## 🚀 Featured Engineering Codebases

### 1. [Contract Agentic Society (CAS)](https://github.com/syedmuhammadayyanibrar/CAS)
- **Domain:** Enterprise Multi-Agent Federation // Contract Lifecycle Management
- **Stack:** Python 3.12, FastAPI, Google Gemini API, Fastn MCP Nervous System, PostgreSQL + asyncpg, React UI, PyTest
- **Highlights:** Federation of six specialized multi-agent societies (Contract, Risk, Negotiation, Compliance, Obligation, Dispute) coordinated via a Contract Mesh Director and Fastn MCP event bus, featuring adversarial debate and 100% benchmark defense grounding.

### 2. [AuraSight: AI Voice Assistant for Blind Shopkeepers](https://github.com/syedmuhammadayyanibrar/AuraSight)
- **Domain:** Accessibility // Edge Multimodal Intelligence // On-Device Audio & Vision
- **Stack:** Kotlin, Jetpack Compose, Whisper ONNX (Urdu STT), Gemma 4 31B (Multimodal Tool-Calling), CameraX, Android SDK
- **Highlights:** Zero-latency offline Urdu speech-to-text, real-time Pakistani rupee currency detection, and Khata ledger management via tactile hardware volume-key triggers.

### 3. [ComplianceOps: Evidence-Driven AI Compliance Auditor](https://github.com/syedmuhammadayyanibrar/compliance-ops)
- **Domain:** Agentic Governance // EU AI Act & Enterprise Policy Audit
- **Stack:** LangGraph, Python, FastAPI, Next.js, pgvector, PostgreSQL, Slack API, Linear API
- **Highlights:** Stateful audit graph (Classify → Plan → Requirements → Evidence → Gaps → Remediation) gathering evidence across code repositories and docs with dual-key human approval before Linear ticket remediation.

### 4. [Negotiation Agent Protocol](https://github.com/syedmuhammadayyanibrar/negotiation_agent)
- **Domain:** Autonomous Multi-Agent Swarms // Game Theory
- **Stack:** Python 3.11+, LangGraph, Game-Theoretic Concession Functions, FastAPI, Docker
- **Highlights:** Dynamic coalition formation algorithms, formal concession curves, and automated Pareto-optimal convergence verification across heterogeneous LLM agents.
