## 🚀 Featured Engineering Codebases

### 1. [Contract Agentic Society (CAS)](https://github.com/syedmuhammadayyanibrar/CAS)
- **Domain:** Enterprise Contract Lifecycle Management (CLM) // Multi-Agent Federation
- **Stack:** Python 3.12, FastAPI, Google Gemini API, Fastn MCP Nervous System, PostgreSQL + asyncpg, React UI, PyTest
- **Highlights:** Federation of six specialized multi-agent societies (Contract, Risk, Negotiation, Compliance, Obligation, Dispute) coordinated via a Contract Mesh Director and Fastn MCP event bus (DocuSign, Slack, Airtable, Google Calendar), featuring adversarial risk debate and 100% defense grounding.

### 2. [ComplianceOps: Evidence-Driven AI Compliance Auditor](https://github.com/syedmuhammadayyanibrar/compliance-ops)
- **Domain:** Enterprise Governance // EU AI Act & Automated Audit
- **Stack:** LangGraph, Python, FastAPI, Next.js, pgvector, PostgreSQL, Slack API, Linear API
- **Highlights:** Stateful audit graph (Classify → Plan → Requirements → Evidence → Gaps → Remediation) gathering evidence across code repositories and docs with dual-key human approval before Linear ticket remediation. 100% safety policy gate compliance across 8 evaluation benchmarks.

### 3. [Autonomous B2B Deal & Procurement Negotiation Engine](https://github.com/syedmuhammadayyanibrar/negotiation_agent)
- **Domain:** Commercial Operations // Multi-Agent Bargaining & Game Theory
- **Stack:** LangGraph, Groq LLM, FastAPI, Redis Checkpoints, Qdrant Vector DB, PostgreSQL, LangSmith
- **Highlights:** Autonomous multi-agent bargaining engine for complex enterprise procurement deals and SLA agreements. Deploys an asynchronous 17-message protocol with sequence verification, behavioral trust modeling, and cooperative coalition formation to resolve deal deadlocks.

### 4. [AuraSight: Edge-Native Voice Transaction & Accounting System](https://github.com/syedmuhammadayyanibrar/AuraSight)
- **Domain:** Edge AI // Tactile Accessibility & Financial Integrity
- **Stack:** Kotlin, Jetpack Compose, Whisper ONNX (Urdu STT), Gemma 4 31B (Multimodal Tool-Calling), CameraX, Android SDK
- **Highlights:** Zero-latency offline Urdu speech-to-text, real-time Pakistani rupee currency detection, and Khata ledger management via tactile hardware volume-key triggers with zero arithmetic hallucinations.
